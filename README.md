# Bounce Back

A vertical climbing arcade platformer built with React, TypeScript, HTML5 Canvas, and Web Audio synthesis.

## Features
- **1P Solo & 2P Local Co-Op** with teammate head-bouncing
- **5 Altitude Zones** scaling up to the 300m Summit
- **Zero-asset Web Audio Synthesizer** for sound effects
- **Local Leaderboard** stored in `localStorage`

## Getting Started

```bash
npm install
npm run dev
```
